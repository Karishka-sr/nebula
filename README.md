# 🌌 Nebula

Персональный хаб продуктивности для Android. Написан на **Kotlin** с использованием **Jetpack Compose** и **Google Material Design 3 (Material You)**.

## Возможности

- **Главная** — цитата дня, прогресс фокуса, быстрая статистика, задачи, вода, настроение, привычки и последние заметки
- **Задачи** — список дел с приоритетами («важно»), фильтрами и отметкой выполнения ✅
- **Заметки** — создание, редактирование и удаление заметок с цветовыми акцентами (локально в DataStore)
- **Привычки** — трекер привычек с недельной сеткой и серией выполнения 🔥
- **Фокус** — Pomodoro-таймер (фокус / короткий / длинный перерыв) с историей сессий
- **Вода** — дневной трекер воды 💧
- **Настроение** — ежедневный mood-трекер 🎭
- **Статистика** — графики активности, воды и настроения за 7 дней
- **Обои Nebula** — коллекция встроенных космических обоев (установка в один тап) 🌌
- **Настройки** — имя, цель фокуса, тема, **Material You (динамический цвет)**, **выбор шрифта** из 6 встроенных гарнитур Google Fonts

## Стек

- Kotlin 2.0.21, Jetpack Compose (BOM 2024.12), Material 3 / Material You
- AGP 8.7, compileSdk 35, targetSdk 35
- Navigation Compose
- DataStore Preferences для локального хранения
- kotlinx.serialization для сериализации
- Встроенные шрифты Google Fonts (кириллица)
- MVVM-подобная архитектура: экраны собирают данные из репозитория

## Сборка

```bash
./gradlew assembleRelease
```

APK появится в `app/build/outputs/apk/release/`.
