# 🌌 Nebula

Персональный хаб продуктивности для Android. Написан на **Kotlin** с использованием **Jetpack Compose** и **Material 3**.

## Возможности

- **Главная** — приветствие, прогресс фокуса за день, быстрая статистика, привычки и последние заметки
- **Заметки** — создание, редактирование и удаление заметок с цветовыми акцентами (хранятся локально в DataStore)
- **Привычки** — трекер привычек с недельной сеткой и серией выполнения 🔥
- **Фокус** — Pomodoro-таймер (фокус / короткий / длинный перерыв) с историей сессий
- **Статистика** — график активности за 7 дней, общее число фокусов и минут, успеваемость по привычкам
- **Настройки** — имя пользователя, дневная цель фокуса, тема (системная / светлая / тёмная)

## Стек

- Kotlin 2.0, Jetpack Compose (BOM 2024.09), Material 3
- Navigation Compose
- DataStore Preferences для локального хранения
- kotlinx.serialization для сериализации
- MVVM-подобная архитектура: экраны собирают данные из репозитория

## Сборка

```bash
./gradlew assembleRelease
```

APK появится в `app/build/outputs/apk/release/`.
